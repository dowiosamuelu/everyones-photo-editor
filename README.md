# Film Cam 底片機

在手機瀏覽器裡用的底片風格相機（PWA）。打開網址就能用，也可以「加到主畫面」當成 App。

## 功能

- 即時取景：取景時就能看到套上底片風格的畫面（需要 HTTPS 和相機權限）
- 匯入照片：從相簿選照片，或用手機相機拍一張再套色
- 14 種風格：柔和暖調、復古暖黃、冷調綠影、過曝粉彩、鮮豔正片、經典負片、經典正片、電影夜色、黑白粗顆粒，以及依參考照片量測調出的琥珀褪色、霧白空間、青藍泳池、灰綠街景、暗調聚光
- 場景選單：選「主要拍什麼／光線／畫面裡有」，自動推薦風格並微調色彩（例如壓住紅葉不爆色、人像膚色提亮）
- 基本調整：濾鏡強度、曝光、色溫、色調（綠 ↔ 洋紅）
- 效果：黑位（壓黑 ↔ 褪色）、白位上限、立體（局部對比）、柔光、暈光、邊緣柔焦、暗角、顆粒、漏光、灰塵・毛髮・刮痕、日期戳記

## 為什麼不是「整張套一層濾鏡」

數位仿底片看起來平，常見原因是每個像素都被同樣處理。這個 App 讓效果依位置與亮度變化：

- 顆粒：暗部多、高光少，強度在畫面上成團不均，RGB 三色強度不同，顆粒越粗細節越少
- 立體：模擬底片顯影的邊緣效應，加強細小紋理，但在強烈明暗交界收斂，避免數位感白邊
- 鏡頭：越靠角落越模糊、越暗（暗角在光線進底片前就發生）
- 光暈：只在亮處周圍擴散；Halation 帶紅橘色
- 顏色：RGB 三層各自的 S 曲線，同一個顏色在亮處與暗處偏向不同
- 漏光、灰塵、毛髮、刮痕：位置隨機，用相機拍時每張都不同

## 隱私

**照片不會上傳到任何伺服器。** 拍照、套色、存檔全部在你的手機瀏覽器裡完成。

| 項目 | 實際行為 |
| --- | --- |
| 拍照／匯入 | 相機畫面與選取的照片只存在瀏覽器記憶體，關掉頁面就消失 |
| 濾鏡運算 | 用手機 GPU（WebGL）在本機計算，不呼叫任何外部 API |
| 網路請求 | 只會下載 App 本身的檔案（`index.html`、`manifest.json`、`sw.js`、兩張圖示），沒有任何上傳 |
| 本機儲存 | `localStorage` 只記住你上次選的風格、場景與滑桿數值，不存照片 |
| 分享 | 只有你按「分享」時，才把照片交給手機系統的分享選單，由你決定要給哪個 App |

GitHub Pages 和所有網站主機一樣，會記錄訪客的 IP 等一般連線紀錄；這是載入網頁本身產生的，和照片無關。

## 使用方式

1. 用手機開啟本專案的 GitHub Pages 網址
2. 允許相機權限（不允許也能用「匯入照片」）
3. iPhone：Safari 分享 →「加入主畫面」；Android：Chrome 選單 →「安裝應用程式」

## 檔案

- `index.html`：整個 App（介面、WebGL 濾鏡、場景推薦規則）
- `sw.js`：Service Worker，讓 App 可離線開啟
- `manifest.json`、`icon-*.png`：PWA 設定與圖示

## 風格與場景規則的依據

各風格參數與場景推薦，整理自富士官方說明、Fuji X Weekly 等配方網站，以及中英日文的攝影調色教學。這些是「參考某款底片的風格」，不是精確重現，也與 Fujifilm、Kodak、CineStill 無關。
